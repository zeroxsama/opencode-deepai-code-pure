号池、配额与用量由插件在 Bun 宿主内直连上游维护。本页是 magpie 沙盒页，只读用量/供应商、可编辑插件选项。

账号 / 登录 / 注册

沙盒页面无 fetch、无表单、read 不给账号 —— 登录与注册按钮由宿主按插件的 auth.methods 原生渲染，或走 MCP 工具。这里给入口。

界面：去「插件 → 已安装」或「供应商」页，找到 deepai 行，点「登录 / 添加账号 / Sign in」→ 选 4 种方式 （填 Key / 导入桌面端凭据 / 浏览器登录 / 注册新账号入池）。

命令行（装了 magpie 的机器）：

magpie plugin login deepai

注册新账号（让 agent 调 MCP 工具，或在登录弹窗选方式四；需先配好邮箱后端选项）：

deepai-pure_register
  1. 填上游 API Key（桌面端凭据文件里的 apiKey）
  2. 导入桌面端凭据（自动读 ~/.deepai-code/.../deepai-account.bin）
  3. 浏览器登录（回环 /auth-callback 换 Key）
  4. 注册新账号入池（lib/register.mjs 流水线）

桌面端登录过、或设了 DEEPAI_API_KEY 时账号自动入池，直接用 deepai/glm-5.3-flash 即可；deepai-pure_accounts 查看号池。
