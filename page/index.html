账号管理

完整号池管理（加 Key / 删号 / 启停 / 分组 / 导入 / 注册 / 查配额 / 设置） 由插件宿主的本地服务提供，在独立浏览器窗口打开——不会改动本沙盒页的 origin， 避免宿主 postMessage 通道被破坏。

服务地址（端口随 adminPort 选项变化；magpie web 远程时用其转发地址）：

http://127.0.0.1:3493/

在新窗口打开账号管理 ↗ （若弹窗被拦截，用此链接或复制地址到浏览器打开）

若打不开，说明服务未启动：重启插件（关→开）后重试，或看 magpie plugin 日志里的「账号管理服务已启动」。

宿主原生登录 / 注册入口

登录表单由 magpie 按插件 auth.methods 渲染：去「插件 → 已安装」 或「供应商」页找到 deepai 行，点「登录 / 添加账号 / Sign in」 → 4 种方式（填 Key / 导入桌面端凭据 / 浏览器登录 / 注册新账号入池）。 或在装了 magpie 的机器上执行：

magpie plugin login deepai

注册新账号：让 agent 调 MCP 工具 deepai-pure_register，或在登录弹窗选方式四 （需先配好邮箱后端选项）。

桌面端登录过、或设了 DEEPAI_API_KEY 时账号自动入池，直接用 deepai/glm-5.3-flash 即可；deepai-pure_accounts 查看号池。
